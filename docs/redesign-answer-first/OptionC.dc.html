Cognitive, not clock — the day is 100% mind work against a 6h pool.

what this buys

A reading never leaves the thing it is about. There is no table to scroll sideways and no accordion to unfold — the whole plan, and everything the model computed about it, is one screen.

what it costs

Columns stop lining up: a 15m task gets a 44px column and can carry no readings at all, so the shortest tasks go blank. Comparing a value down the list — the one thing the table is good at — gets harder, not easier. And it does not survive a phone.
